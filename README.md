# ✈️ VOYARA AI — Your Personal Travel Agent

**You Dream It. We Plan It. You Approve It. We Book It.**

🌐 **Live Website:** https://voyara-ai-travel.streamlit.app/

## About the Project

VOYARA AI is an AI-powered travel planning application developed using Python, Streamlit, Object-Oriented Programming (OOP), and Google's Claude AI.

The application helps users plan personalized trips based on their destination, travel dates, budget, and preferences. Users can also interact with an AI travel concierge, explore accommodation options, access travel emergency guidance, and save their travel plans.

## Main Features

1. 🌍 **Plan My Trip** — Generate personalized travel itineraries based on user preferences and budget.
2. 🏨 **Hotels & Mobility** — Explore accommodation recommendations and booking options.
3. 💬 **AI Concierge** — Ask questions, request recommendations, and refine travel plans through AI-powered conversations.
4. ✅ **Review & Approve** — Review travel arrangements before approving a proposed itinerary.
5. 🆘 **Travel SOS** — Access emergency travel guidance for situations such as medical emergencies, lost baggage, or cancelled flights.6. 6. 🧳 **Travel Readiness** — Check travel documents, packing essentials, and important preparations before departure.
7. 📚 **My Saved Trips** — Save and revisit previously created travel plans.

## Technologies Used

- Git and GitHub — Version control and project submission

## Object-Oriented Programming

VOYARA AI demonstrates OOP concepts through its Python class structure, including:

- **Classes and Objects** — Represent travel assistant components and their behavior.
- **Inheritance** — Specialized assistant classes extend shared functionality.
- **Polymorphism** — Different assistant classes provide their own implementations of common methods.
- **Abstraction** — A shared parent class defines behavior that child classes implement.

## How to Run the Project

1. Clone or download the GitHub repository.
2. Install the dependencies listed in `requirements.txt`.
3. Create a `.env` file containing your own Claude API key:

   `Claude_API_KEY=your_api_key_here`

4. Start the application:

   `python3 -m streamlit run app.py`

5. Open the local Streamlit URL shown in the terminal.

## Important Notes

VOYARA AI is an academic prototype. Travel suggestions and estimated costs should be verified before making real travel arrangements. Booking-related features do not independently confirm or complete real reservations or payments.

The Claude API key is stored locally in `.env` and is not included in this repository.
